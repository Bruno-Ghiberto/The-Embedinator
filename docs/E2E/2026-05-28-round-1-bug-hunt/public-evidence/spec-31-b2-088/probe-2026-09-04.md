# BUG-088 / BUG-082 live probe — 2026-09-04 (spec-31 Batch 2 unit 4, task 2.7)

**Question (088)**: with an LLM call in flight and the Ollama container frozen, does the backend end
the turn on its own deadline, and does the user see an honest error before the client's 120 s idle
watchdog fires? **Record**: the same scenario ran **553 s** unbounded (P4-S6, 2026-07-08, trace
`8ba310a8…`) while the user saw a dead stream.
**Question (082, best effort)**: does the injection-style message that cycled 24 classifications in
the original hunt terminate?

BUG-082 live: the message that reliably classified "ambiguous" on 2026-07-03 was classified
`rag_query` today (the classifier is not deterministic), so the direct-ambiguous route was not
exercised on the live stack; the turn terminated normally in 9.8 s. The deterministic proof for the
direct route is the real-socket gate `test_backend_bounds_the_ambiguous_intent_cycle`
(`always_ambiguous`: pre-fix `error RECURSION_LIMIT`, post-fix `done` with text) and the
integration test that pins one classification per turn.

**Side observation for Batch 7 (BUG-083):** the model COMPLIED with the injection — it answered
"pwned" with 7 sources and High (96 %) confidence. The BUG-082 record noted that on 2026-07-03 the
injection did NOT succeed (the loop pre-empted any output). With the loop fixed, the injection's
compliance is now observable: input for task 7.1/7.2's regression corpus.
